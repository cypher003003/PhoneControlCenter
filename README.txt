# Phone Control Center — HTML Starter

This is the first, browser-based part of the project.

Files:
- index.html
- style.css
- app.js

Current features:
- Responsive HTML dashboard
- Browser camera preview/capture
- User-selected file/photo preview list
- Placeholder areas for calls, SMS, notifications and laptop transfer

Next stage:
A small Android bridge will be added so the same HTML dashboard can receive Android call/SMS/notification data and expose local Wi-Fi file transfer.

Important:
A normal browser cannot read Android SMS, call logs, or notification contents. Those features require Android permissions and a native bridge.
